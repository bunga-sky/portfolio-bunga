# Bunga Rahmadani — Portfolio

Personal portfolio website of **Bunga Rahmadani**, Aspiring Data Scientist.

## 🛠️ Tech Stack
- **React + Vite**
- **Tailwind CSS**
- **Framer Motion** (animations)
- **Lucide React** (icons)

## 🏃 Run locally
```bash
npm install
npm run dev
```
Open http://localhost:5173

## ✏️ Edit content
All text, projects, and certificates are in `src/data.js`.

## 🚀 Deploy
Deployed on Vercel. Import this repository at vercel.com and click **Deploy**.
